ArchivingDreams

This is a project dedicated to reverse engineering Dreams' server endpoints and archiving as much as we can.

Progress

Oct 11: We've been able to identify all these routes, but we've had no luck actually trying to get anything from them. It's possible that they're just down, much like the website, but the other possibility is that the game is sending some sort of token or header to confirm to the Dreams servers that the game is legitemate. Of course, we'd need to spoof that, so that's what I'm checking on next.

How we've derived these routes

These routes have been directly derived from a decompiled version of Dreams. We're specifically using Ghidra, but if you wanted to replicate this, Binja and IDA Pro will do just fine.

Services and their methods

Dreams' services are accessed through https://prod.puprod.indreams.me/puserver.v1.[SERVICE]/[METHOD]
